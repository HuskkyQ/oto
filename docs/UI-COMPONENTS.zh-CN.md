## 怎么读这份文档

四层，每一层只使用它上面的一层：

| 层 | 位置 | 内容 |
|---|---|---|
| 令牌 | `Design/Theme.swift` | 颜色、字号阶梯、间距、圆角 |
| 基元 | `Components/` | 背景、玻璃表面——不含内容 |
| 组件 | `Components/` | 头部、行、图表、徽章、表单（即本文） |
| 页面 | `Features/` | 只做组合，自己不绘制 |

- **编号是稳定的。** 组件改变形态时保留编号、增加一个变体；永不重新编号。文档、代码与评审都用
  这些编号互相引用。
- **复用** 统计有多少个页面显示它。`1` 表示只用一次：除非它很长或自带状态，否则先留在页面里，
  以后再议。
- **已实现** 给出实现文件，尚不存在则写 `—`。文件可以是部分的，说明里写清差多少。

页面缩写：**Onb** 引导 · **Live** 实时 · **Drv** 行程 · **DrvD** 行程详情 · **Chg** 充电 ·
**ChgD** 充电详情 · **Stats** 统计 · **Hist** 历史轨迹 · **Set** 设置。

### 1.1 C-02 `HeaderBar` —— 参考实现

全篇唯一带真实行为的组件，所以写全。其余组件都只是静态布局。

**两个状态，一条栏。栏内没有任何东西移动。**

| | 静止 | 包裹 |
|---|---|---|
| 内缩 | 通栏，与 16 pt 内容边距对齐 | 两侧各 12 pt |
| 圆角 | 0 | 28 |
| 内边距 | 14 / 16 / 12 | 10 / 16 |
| 表面 | 无——没有玻璃、没有描边、没有阴影 | 玻璃主体、反光描边、顶部内高光、阴影 `0 14 30` 黑 32% |
| 背景模糊 | — | blur 30 pt，饱和度 180% |
| 触发 | 滚动偏移 0 | 页面移动约 8 pt |

- **过渡：** 内缩、内边距与圆角走 220 ms `cubic-bezier(.32, .72, 0, 1)`；玻璃用自己的曲线在 180 ms
  内淡入。滚回顶部时按同一条路径反向解开，不跳变。
- **整段滚动都固定**，不随内容一起上移。包裹后内容从它**后面**穿过——这正是它需要模糊、也正是静止
  态背后什么都没有的原因。
- **标题块尺寸永不变化**，所以每个页面的头部高度一致。在它下面再放一条玻璃栏，就是早期版本读起来
  像「叠起来的横带」的原因——筛选行（C-04）属于内容。
- **动作是裸图标**（C-03）：白 74%、36 pt、无圆形底、无边框、无阴影。玻璃胶囊里再套一个玻璃圆形，
  会被读成第二种材质。
- **设置是推入页，不是底栏 tab。** 实时页 header 最后一个动作是齿轮，点开是全屏设置页，自带返回，
  悬浮栏隐藏。
- **`bleed`** 给内容没有左右内边距的页面（历史轨迹的地图）：静止内缩 0，包裹内缩 12。
- **`forced-wrapped`** 给地图优先的页面：历史轨迹压在地图上，地图颜色之上的无边框标题看不清。
  自己不滚动的页面不会自动包裹。
- **减弱动态效果：** 完全不做过渡，两个状态瞬间切换。
- **平台不支持背景模糊：** 包裹态主体改为不透明 `#18222F`，描边不变，标题后面不会透出内容。静止态
  不需要退路。
- **可读性：** 包裹态主体保持 ≥ 5% 白，使内部 12 pt 说明文字在深蓝底上仍有 4.5 : 1。对比度不够时
  提高主体不透明度——绝不把文字调亮。

> **实现注记（iOS 17 目标）。** `.onScrollGeometryChange` 是 iOS 18+，所以触发来自具名坐标空间加
> 一个报告内容偏移的 `PreferenceKey`。头部是固定在滚动视图顶部的 overlay，内容带一个等于静止态高度
> 的顶部内边距；包裹后的胶囊是同一个视图换了修饰符，不是第二个头部。不需要
> `matchedGeometryEffect`。

| C-11 | `SettingsGroup` | 包裹一组行的圆角容器；分隔线由行自己绘制 | — | 1 个页面，4 组 | `SettingsGroup.swift` |
| C-12 | `SettingsRow` | 标签、弱化数值、尾部控件或箭头 | 数值 / 箭头 / 开关 / 破坏性 | 1 个页面，N 行 | `SettingsGroup.swift` |
| C-13 | `MapEntryCard` | 缩略图、标题、副标题、箭头——一张可跳转的卡片 | — | 1 | 内联在 `StatsView.swift`（只用一次，见下） |

- **C-09 与 C-10 的区别：** 卡片带外阴影；卡片**内部**的东西（图表、磁贴、分组）只取软主体与内高光。
  叠两层阴影，玻璃就会读成塑料。
- **着色是语义，不是装饰：** 绿表示能耗、橙表示警告、红只用于破坏性操作——且从主体与描边渐变里进入，
  绝不使用纯色平涂。
- **C-13 目前只用一次**（统计 → 历史轨迹）。在第二个页面需要它之前，先留在页面里。

| C-41 | `MiniBars` | 六到七根紧凑柱，无轴、无网格，柱下只有一个短标签 | 默认 / 高亮一列 | 2（实时、动能回收） | `MiniBars.swift` |
| C-43 | `ComparisonRow` | 一行分组对比：条 + 数值 + 差值 + 贯穿所有行的均值竖线 | 最优 / 常规 | 1（能耗分析） | 留在页面内 |
| C-44 | `MonthCalendar` | 七列月历，每格日期、最多两个标记与当日里程 | 有事件 / 今天 / 空 | 1（行程日历） | 留在页面内 |

- **图表不会随 3 秒轮询重新播放动画**——只在时间范围变化时。用户正在读的屏幕上一张「一呼一吸」的
  图，就是噪声。
- 同一页面的多张图默认共享 x 轴，纵向对照才对得上；某一张被缩放后，其余各按各的窗口画。
- **时间轴可缩放。** 双指捏合以中心为锚点缩放（最近缩到两个桶），横向拖动平移，双击回到整个周期。
  每张图各自持有窗口，缩放一张不会带动其他图；切换时间段或日/月粒度会清空它。以竖向为主的
  拖动会被忽略，页面照常滚动。

## 11. 让它保持可复用的规则

- **组件从不取数据。** 它接收数据、回调，别的一概不要；视图模型留在页面里。
- **组件不知道自己在哪个页面。** `Components/` 里不该出现任何 `if screen == .live`。
- **文案由外部传入**（NFR-9）。`StateBadge` 现在内部把 `state` 映射成中文标签；这张映射表应移到
  格式化器里，让视图与语言无关。
- **只有一个强调色。** 需要第二种强调色的组件，是设计错误，不是一个参数。
- **颜色即状态。** 青色表示选中、绿色表示健康、橙色表示警告、红色表示破坏。因为「这个页面就是这个
  页面」而选的颜色，是没人能再改的主题的开端。
- **第二次用到时才抽取**，或者当它 ≥ 约 40 行、或自带动画时。C-13 与 C-14 目前都只用一次；C-14 因为
  有状态而值得单独成文件，C-13 不值得。
- **八个参数的组件其实是三个组件。** 变体上限三个；出现第四个，说明抽象错了。
