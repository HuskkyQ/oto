Dark-only, Chinese-first, data-first, Liquid Glass. Every surface is translucent glass over a tinted backdrop: bright specular rim, one soft inner highlight, no flat panels. Every screen maps to a read-only API route and to real fields that already exist in the server. Values below are representative, not a live capture. Scroll inside any phone frame to see the pinned header and filter bar. Full specs: docs/UI-DESIGN.md. Screens beyond v1 are in gap-screens.html.
